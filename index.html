What I do

Most of my work lives at the boundary between design systems and browser performance: defining component APIs that stay stable for years, migrating legacy implementations without breaking the applications built on them, and cutting rendering cost where it actually shows up for users.

I care a lot about accessibility, incremental migration paths, and leaving code that the next engineer can reason about.
