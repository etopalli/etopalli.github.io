How this site is made

This is a static site. HTML and CSS, no framework, hosted on GitHub Pages at etopalli.github.io.

Headings are Baskervville. Everything else is Inter. The cream, rust, and ivory come from looking hard at Fonzi and then using less of it.

Type is set for reading: one column, about 42 rem wide, with a print stylesheet so the résumé page can go to paper without the chrome. Color follows the system — light or dark, whichever you have on.

I built it in Cursor, the same editor I use at work. The source is public at etopalli/etopalli.github.io.
